# 16ジャンルの料理写真

このフォルダの写真は、ホーム・ジャンル投票・ジャンル結果で共用します。画像を生成・加工する処理や外部写真の自動取得はありません。

## 配置手順

1. 以下のファイル名でJPEGをこのフォルダへ保存します。同名の既存写真を置き換える場合は、元の写真を手元に保管してください。
2. 開発環境をDocker Composeで起動し、`/home-preview`と`/genre-vote`を再読み込みします。
3. ホームの3枚と、投票を進めたときの全16枚の対応・切り抜きを確認します。画像を差し替えた直後に以前の写真が表示される場合は、開発用ブラウザーのキャッシュを無効にして再読み込みしてください。

URLは`/images/genres/01-ramen.jpg`のように指定し、`public`を含めません。対応は`src/features/genre-vote/genres.ts`の各IDの`imagePath`で一元管理します。表どおりの配置ならコード変更は不要です。ホームの位置は左カフェ・中央ラーメン・右寿司で固定され、投票順には依存しません。

未配置・読み込み中・読み込み失敗時もカードの寸法を維持し、既存の代替表示を使います。写真は`object-fit: cover`で中央を切り抜き、引き伸ばしません。写真の利用権限は配置する側で確認してください。
