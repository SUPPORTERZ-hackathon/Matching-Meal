# 店舗画像

店舗投票の写真は現在未登録です。写真なしは正常な表示状態で、共通サイズのプレースホルダーを表示します。

ローカル画像を追加する場合はこのフォルダへ保存し、表示用店舗データの`photoUrl`を`/restaurants/ファイル名.webp`に設定してください。コンポーネント変更は不要です。

将来APIから受け取るHTTPSの写真URLも`photoUrl`で扱えます。`next/image`のunoptimizedで直接表示し、Nextの画像設定やAPI通信を追加しません。公式由来データは`source: "hotpepper"`としてクレジットを表示します。架空データ・仮画像に公式提供の表記を付けないでください。
