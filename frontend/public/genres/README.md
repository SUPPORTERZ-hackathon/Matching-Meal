# ジャンル写真の追加

初期状態は写真なしのプレースホルダーです。未設定・読み込み中・取得失敗でも投票できます。

1. このフォルダへ写真を保存します。例: `ramen.webp`。
2. `src/features/genre-vote/genres.ts`の対象ジャンルへ`imagePath: "/genres/ramen.webp"`を設定します。

公開URLに`public`は含めません。ローカルの絶対パス（`/genres/`から始まるURL）を使用します。外部URLは対象外です。IDや表示順、カードのコードを変更する必要はありません。

写真はWebP/JPEG/PNG等で用意し、料理を中央に配置することを推奨します。カードは共通の5:6領域（最大高さ432px）へ`object-fit: cover`で切り抜きます。異なる縦横比の写真でもカードの大きさは変わりません。追加する写真の利用権限は用意する側で確認してください。
