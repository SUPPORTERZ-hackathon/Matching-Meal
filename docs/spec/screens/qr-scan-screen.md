# QRコード参加画面 仕様書

## 1. 画面概要

QRコードを読み取って、既存のルームに参加するための画面。

カメラを利用できる場合はQRコードの読み取りを行い、カメラを利用できない場合は、LINEなどで共有された参加用URLから参加できることを案内する。

## 2. 起動方法・アクセスURL

Docker Composeでフロントエンドを起動した状態で、以下のURLにアクセスする。

- QRコード参加画面：http://localhost:3000/qr-scan
- Home画面：http://localhost:3000/home-preview

Home画面の「QRコードから参加する」ボタンからもQRコード参加画面へ遷移できる。

## 3. 画面構成

- 共通ヘッダー
  - アプリロゴを中央に表示
  - 左側にホーム画面へ戻るボタンを配置
- タイトル
  - 「QR SCAN」
  - 「ルームに参加」
- 説明文
  - 「参加するルームのQRコードを読み取ってください」
- カメラ表示領域
  - カメラアイコン
  - カメラの利用状態に応じたメッセージ
  - カメラ操作ボタン
- ホームに戻るリンク
  - 画面下部に配置

## 4. カメラの表示状態

### 通常表示

- カメラアイコンを表示
- 「カメラを起動してください」と表示
- 「QRコードの読み取りにのみ使用します」と表示
- 「カメラを許可する」ボタンを表示

### カメラ利用不可時

- 「カメラを利用できません」と表示
- 「カメラを利用できない場合は、LINEなどで共有されたURLから参加できます。」と案内
- 「もう一度試す」ボタンを表示

※ 現段階では画面表示の切り替えを確認するための仮実装であり、実際のカメラ起動・QRコード読み取り処理は未実装。

## 5. 画面遷移

| 操作 | 遷移先 |
|---|---|
| Home画面の「QRコードから参加する」 | QRコード参加画面 |
| ヘッダーの戻るボタン | Home画面 |
| 画面下部の「ホームに戻る」 | Home画面 |

## 6. デザイン方針

- スマートフォンでの利用を想定したレイアウト
- 赤色をアクセントカラーとして使用
- カメラ表示領域は濃いグレーの角丸デザイン
- アイコン・説明文・ボタンを中央に配置
- 画面幅に応じて文字やレイアウトが崩れないように調整
